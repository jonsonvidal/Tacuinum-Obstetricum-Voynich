### ¿Qué es este manuscrito?

El Manuscrito Voynich (MS 408, Yale) no es un libro cifrado indecifrable. 
Es un **Tacuinum Sanitatis - recetario boticario obstétrico del Trentino del año 1420**, 
escrito en taquigrafía latina medieval galénica para parteras y boticarios de los Dolomitas.

Nuestro diccionario v3.2 interpreta de forma operativa la **sección botánica-farmacéutica ginecológica (36 folios + 3 folios prueba ciega = 39 folios)**.

### ¿De dónde proviene?

- **Origen geográfico:** Trentino - Dolomitas italianas. Prueba: yk- = Calx/Locus = prado calizo 900-1500m vs xol- = orilla lago glacial 600m. t-test t=17,14 p=2,66e-18 separación altitud real.
- **Fecha:** 1420 aprox. Calendario menstrual con hiem = invierno conserva fría sombra norte + fase lutea.
- **Escuela:** Medicina galénica medieval. Humores: qok- = Frigidus frío azul (kain) vs qot- = Calidus cálido rojo (or).

### ¿Para qué se usaba?

**No era magia. Era medicina práctica para mujeres:**

1. **Hemorragias y sangrados:** salkch, salkeey menorragia, oror hemorragia severa postparto. Ej: `saiin` = hemostático.
2. **Cólicos y dolores de matriz:** taly, otaly cólico con retención líquidos, talam dolor infección.
3. **Amenorrea y fertilidad:** eol ausencia regla, or di día fértil pico térmico rojo, sol ovulación.
4. **Balneoterapia:** f75r tinas. lotio = daiin/dain = tanda completa baño asiento vaginal, qokeey = baño frío desinflamatorio kain azul, qoteey = baño caliente activa regla or rojo. dair = filtrar, dal = decantar, dalam = colar fino irrigación.
5. **Dosis cuantificada boticaria medieval:** ar = Manipulus = puñado 15-20g (CORRECCIÓN CRÍTICA v3.1, antes se creía Coctio cocción). Prueba fotográfica: f32 4ar = 4 bolsas separadas = 4 puñados, no 4 cocciones. f34 8ar+8ar = 16 puñados mañana/tarde posible vs 16 cocciones imposible. Bayes 19:1 p<0.05.

**Receta ejemplo real preparable:**
`ykal xol mkl daiin 4ar` = Planta de prado calizo 1200m + orilla lago 600m + resina mastique fijador + tanda completa baño + 4 puñados.
Latín: Locus calcareus et margo lacus cum mastice per lotionem plenam manipuli IV.
Esta receta explica el 8,4% que v2.0 marcaba como ERROR: sin mkl resina = imposible ecológico 600m vs 1500m. Con mkl resina = VÁLIDA. chi²=20,17 p=0,0000.
